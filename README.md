# Topps Handyman Website

Official website for **Topps Handyman**, built as a responsive static site and deployed with **GitHub Pages**.

## 🔧 Features

- Fully responsive design (desktop & mobile)
- Customer Reviews section with:
  - star ratings
  - search, sort and filter
  - animated **Read more / Show less**
- Contact form powered by **Formspree**
- Black & gold branding
- Clean and accessible layout

---

## 📄 Pages

- **Home** – introduction & branding
- **Our Services** – handyman services overview
- **Reviews** – customer feedback with dynamic filtering
- **Contact** – contact details and message form

---

## ⭐ Reviews system

- Reviews are rendered dynamically using JavaScript
- Long reviews are collapsed by default
- Clicking **Read more** expands the review with animation
- Review layout remains consistent (button & date fixed)

---

## 🛠️ Built with

- HTML5  
- CSS3 (Grid & Flexbox)  
- Vanilla JavaScript  
- Formspree (contact form)  
- Google Analytics (GA4)

---

## 🚀 Deployment (GitHub Pages)

This site is deployed using **GitHub Pages**.

### Live website:
👉 https://toppsonia-web.github.io/

### How it works:
- The repository contains a static website
- The `main` branch is used as the source
- GitHub Pages serves the site automatically
